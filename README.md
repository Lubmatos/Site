# 🌐 Site Profile — Portfólio Pessoal

Projeto desenvolvido com o objetivo de servir como site de portfólio profissional, apresentando informações pessoais, habilidades e projetos de forma clara e acessível para recrutadores.

Este projeto foi desenvolvido como atividade acadêmica na Faculdade Newton Paiva.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Visual Studio Code

## 📱 Responsividade e Aprendizado

O principal desafio do projeto foi a criação de um layout responsivo, garantindo uma boa experiência em diferentes tamanhos de tela. Durante o desenvolvimento, consegui evoluir bastante nesse aspecto, aplicando conceitos de estruturação, estilização e organização do código.
Para apoiar o aprendizado e aprimorar a implementação, utilizei:

- Exemplos disponíveis no GitHub
- Conteúdos do YouTube
- Ferramentas de apoio como ChatGPT e Gemini

Todo o desenvolvimento foi realizado no VS Code, com foco principalmente em HTML e CSS, reforçando boas práticas de front-end.
